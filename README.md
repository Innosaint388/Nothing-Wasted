# ♻️ Zero Waste Food Loop

A simple browser game for **grades 5 and 6** about closing the food waste loop.
Players sort leftovers using the **Food Rescue Ladder** (use it up, share it, feed animals, make something, compost, trash last), then close the loop in the garden.

## Levels
1. **My Kitchen:** sort home leftovers.
2. **School Lunch:** prevent waste first, then share or compost.
3. **The Garden Loop:** answer questions to close the loop.
4. **Bonus, Peanut Farm:** dry, test and sort a harvest (based on the SmartDry-Store-Test Hub concept).

## Design choices for kids
- Large buttons, one decision at a time, no timers, no game over, gentle feedback from a worm mascot.
- Optional read-aloud, keyboard accessible, works on Chromebooks and phones.
- No accounts, ads or tracking. Progress is saved only on the device (localStorage).

## Run locally
Open `index.html` in a browser. There is no build step.

## Edit the content
All items, bins, levels and facts are in `data.js`. A teacher guide with an answer key is in `teachers.html`.
Every teaching statement is a **draft** and should be reviewed before classroom use.
